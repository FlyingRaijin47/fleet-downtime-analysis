# Fleet Downtime Analysis Dashboard

## Project Overview

This project analyzes fleet operations and maintenance data to evaluate vehicle downtime, maintenance costs, driver efficiency, incident trends, and maintenance activity.

The analysis was developed in Excel and presented through an interactive dashboard designed to support operational monitoring and maintenance decision-making.

## Key Metrics

The dashboard summarizes:

- Total Trips: 85,410
- Total Downtime Hours: 72,230.5
- Downtime Rate: 3%
- Maintenance Efficiency: 5.92
- Total Incidents: 170
- Total Labor Cost: 1.3M
- Total Missing Truck Assignments: 2%

## Analysis Areas

- Maintenance cost by truck
- Driver efficiency ranking
- Downtime distribution by truck status
- Incident trend by year
- Downtime trend by year
- Maintenance spare-cost breakdown
- Interactive filtering by truck, facility location, maintenance type, year, and status

## Tools & Technologies

- Microsoft Excel
- Power Query
- DAX
- Pivot-based analysis
- Interactive dashboard design
